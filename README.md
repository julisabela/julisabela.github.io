Para este trabalho, decidiu-se retratar os abalos na cidade de João Câmara, pois se trata de um fenômeno muito característico da região.
Utilizamos um template disponibilizado pelo professor Lucas Dantas como base para o desenvolvimento do site. A partir dele, empregamos CSS e JavaScript para tornar o site mais interativo e atraente.
